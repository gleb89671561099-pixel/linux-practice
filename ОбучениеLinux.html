📦 Установка Linux

💡 Что это: Linux — это бесплатная операционная система, как Windows или macOS, но с открытым исходным кодом. Существует множество «вариантов» (дистрибутивов). Мы рассмотрим два самых популярных: Ubuntu (для новичков) и Arch Linux (для продвинутых).
✅ Ubuntu идеален для новичков. Красивый интерфейс, огромная поддержка, всё работает «из коробки».

Шаг 1 — Скачайте образ Ubuntu

Зайдите на официальный сайт ubuntu.com/download/desktop

Нажмите кнопку Download (Скачать)

💡 Скачивание начнётся автоматически — файл весит около 4 ГБ

Шаг 2 — Запишите на флешку

Вам понадобится флешка минимум на 8 ГБ. Данные с неё будут удалены!

Скачайте программу Rufus (для Windows) или BalenaEtcher (для Windows / macOS / Linux)

Rufus — rufus.ie
Скачать: https://rufus.ie

Запустите программу, выберите скачанный ISO-образ и вашу флешку, нажмите «Старт»

Шаг 3 — Загрузитесь с флешки

Вставьте флешку в компьютер и включите его

Нажмите кнопку вызова загрузочного меню (обычно F12, F9, Esc или F2 — зависит от компьютера)

💡 Если не знаете — попробуйте F12 или Esc

Выберите вашу флешку (UEFI: …) и нажмите Enter

Шаг 4 — Установите Ubuntu

Выберите язык — Русский, затем «Запустить Ubuntu без установки»

Проверьте, что всё работает (Wi-Fi, звук, экран). Нажмите «Установить Ubuntu»

Выберите тип установки:

ВариантКогда выбрать
Удалить диск и установитьЕсли у вас один диск и вы хотите только Linux
Рядом с WindowsЕсли хотите выбирать систему при включении

Выберите часовую зону и раскладку клавиатуры (Русская)

Придумайте имя пользователя и пароль

💡 Запомните пароль — он понадобится при установке программ

Нажмите «Установить» и ждите 10–20 минут. Затем перезагрузите компьютер и выньте флешку

⚠️ Arch Linux устанавливается вручную через командную строку. Здесь нет графического установщика. Вы будете собирать систему по частям. Рекомендуется, если вы хотите разобраться, как работает Linux изнутри.

Шаг 1 — Скачайте образ Arch Linux

Зайдите на archlinux.org/download и скачайте последний ISO-образ

Запишите на флешку с помощью Rufus (в режиме DD) или BalenaEtcher

💡 В Rufus при записи Arch ISO выберите «DD-режим» вместо «ISO-режима»

Шаг 2 — Загрузитесь с флешки

Вставьте флешку, включите ПК, вызовите загрузочное меню (F12 / Esc / F9)

Выберите флешку — вы попадёте в командную строку Arch

Шаг 3 — Подготовьте диск

Проверьте, какой диск у вас:

Проверка диска
lsblk

Удалите все данные и создайте таблицу разделов (замените sda на ваш диск!):

Создание разделов
parted /dev/sda mklabel gpt
parted /dev/sda mkpart primary ext4 1MiB 513MiB
parted /dev/sda mkpart primary ext4 513MiB 100%
parted /dev/sda set 1 boot on

Создайте файловую систему и активируйте:

Форматирование
mkfs.ext4 /dev/sda1
mkfs.ext4 /dev/sda2
mount /dev/sda2 /mnt
mkdir /mnt/boot
mount /dev/sda1 /mnt/boot

Шаг 4 — Установите базовую систему

Установите базовые пакеты:

Установка базовой системы
pacstrap /mnt base linux linux-firmware networkmanager vim

Создайте файл конфигурации:

Генерация fstab
genfstab -U /mnt >> /mnt/etc/fstab

Перейдите в новую систему:

Chroot
arch-chroot /mnt

Шаг 5 — Настройте систему

Установите часовой пояс:

Часовой пояс
ln -sf /usr/share/zoneinfo/Europe/Moscow /etc/localtime
hwclock --systz

Раскомментируйте en_US.UTF-8 UTF-8 в файле /etc/locale.gen:

Локаль
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf

Установите имя компьютера:

Имя хоста
echo "arch" > /etc/hostname

Установите пароль для root и создайте пользователя:

Пользователи
passwd
useradd -m -g users -G wheel,storage,power -s /bin/bash yourname
passwd yourname
💡 Замените yourname на своё имя пользователя

Установите загрузчик GRUB:

Загрузчик GRUB
pacman -S grub efibootmgr
grub-install --target=x86_64-efi --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg

Шаг 6 — Графический интерфейс (опционально)

Arch устанавливается без графического интерфейса. Чтобы его получить, установите GNOME:

Установка GNOME
pacman -S xorg xorg-server gnome gnome-session
systemctl enable gdm

Выйдите из chroot и перезагрузитесь:

Перезагрузка
exit
umount -R /mnt
reboot
💡 Не забудьте вынуть флешку!

🔄 Обновление системы

💡 Зачем обновлять: Обновления содержат исправления ошибок, новые функции и, самое главное — исправления безопасности.

Откройте терминал. Нажмите Ctrl + Alt + T

Обновите списки пакетов:

Обновление списков пакетов
sudo apt update
💡 sudo — команда для выполнения от имени администратора. Введёте свой пароль

Обновите установленные программы:

Обновление программ
sudo apt upgrade

Для полного обновления (включая замену ядер):

Полное обновление
sudo apt full-upgrade

Откройте терминал (Ctrl + Alt + T)

Обновите всю систему одной командой:

Обновление Arch
sudo pacman -Syu
💡 В Arch это единственная команда для обновления. Она сама обновит и списки, и пакеты

Если используете AUR (пользовательские пакеты):

AUR helper (yay)
yay -Syu

📲 Установка программ

💡 Как это работает: В Linux программы устанавливаются через «менеджер пакетов» — это как App Store, но в командной строке. Менеджер сам скачает программу и все нужные зависимости.

Основные команды

КомандаЧто делает
sudo apt updateОбновить списки программ
sudo apt install имяУстановить программу
sudo apt install имя1 имя2Установить несколько программ

Примеры установки

Установить браузер Chrome:

Google Chrome
sudo apt install google-chrome-stable

Установить VLC (видеоплеер):

VLC
sudo apt install vlc

Установить текстовый редактор VS Code:

VS Code
sudo apt install code

Установка через Snap

Ubuntu также поддерживает Snap — универсальные пакеты:

Snap
sudo snap install telegram-desktop
sudo snap install spotify

Основные команды

КомандаЧто делает
sudo pacman -S имяУстановить программу
sudo pacman -S имя1 имя2Установить несколько программ

Примеры установки

Установить браузер Firefox:

Firefox
sudo pacman -S firefox

Установить Telegram:

Telegram
sudo pacman -S telegram-desktop

Установить несколько программ сразу:

Несколько программ
sudo pacman -S vlc gimp filezilla

Установка из AUR (Arch User Repository)

В AUR есть программы, которых нет в официальных репозиториях. Установите помощника yay:

yay — AUR helper
sudo pacman -S base-devel git
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

Теперь можно устанавливать программы из AUR:

Установка из AUR
yay -S google-chrome

🗑️ Удаление программ

Удалить программу (сохраняя конфигурационные файлы):

Удаление (файлы настроек останутся)
sudo apt remove имя_программы

Удалить программу и её конфиги полностью:

Полное удаление
sudo apt purge имя_программы

Удалить ненужные зависимости:

Очистка
sudo apt autoremove
💡 Рекомендуется запускать после удаления программ — это освободит место

Удаление Snap

Snap
sudo snap remove telegram-desktop

Удалить программу (сохраняя конфиги):

Удаление
sudo pacman -R имя_программы

Удалить программу и зависимости, которые больше не нужны:

Удаление с зависимостями
sudo pacman -Rs имя_программы

Очистить кэш пакетов (освобождает место):

Очистка кэша
sudo pacman -Sc
💡 Это удалит скачанные файлы пакетов, но не установленные программы
