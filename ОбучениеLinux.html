Установка Linux

Выберите ваш вариант установки. Если не уверены — начните с виртуальной машины: это безопасно и ничего не сломает.

1

Скачайте ISO-образ

Перейдите на официальный сайт Ubuntu и скачайте последнюю LTS-версию (Long Term Support — долгосрочная поддержка).

ссылка
https://ubuntu.com/download/desktop
2

Создайте загрузочную флешку

Возьмите флешку от 4 ГБ и запишите на неё ISO-образ с помощью Balena Etcher (Windows / macOS / Linux) или Rufus (Windows).

💡 Программа записи Balena Etcher — https://etcher.balena.io
3

Загрузитесь с флешки

Вставьте флешку, включите компьютер и войдите в Boot Menu. Обычно это клавиши F12, F8, F10 или Esc при включении.

Выберите пункт «Try or Install Ubuntu».

4

Установите систему

Запустится установщик. Выберите язык → «Установить Ubuntu рядом» (если хотите оставить Windows) или «Стереть диск и установить Ubuntu».

Создайте имя пользователя и пароль — они понадобятся для входа и команд sudo.

5

Первая команда после установки

После перезагрузки откройте терминал (Ctrl+Alt+T) и обновите систему.

ubuntu / debian
sudo apt update && sudo apt upgrade -y
1

Скачайте Arch ISO

Arch — система «собери сам»: вы получаете минимум и добавляете только то, что нужно именно вам.

ссылка
https://archlinux.org/download/
2

Проверьте загрузку (UEFI)

Убедитесь, что загрузились в UEFI-режиме — если команда вернёт пустую строку, система загрузилась в Legacy/BIOS.

проверка
ls /sys/firmware/efi/efivars
3

Настройте интернет

Для проводного соединения обычно ничего делать не нужно. Для Wi-Fi используйте iwctl.

wi-fi через iwctl
iwctl
[iwd]# station wlan0 scan
[iwd]# station wlan0 get-networks
[iwd]# station wlan0 connect "Имя_сети"
[iwd]# exit
4

Разметьте диски

Посмотрите названия дисков, затем создайте разделы в cfdisk или fdisk.

разметка
lsblk
cfdisk /dev/sda
5

Отформатируйте и смонтируйте разделы

Ниже — базовый вариант для одного раздела ext4. Замените /dev/sdaX на свой номер раздела.

форматирование
mkfs.ext4 /dev/sda2
mount /dev/sda2 /mnt

Если у вас UEFI — отдельно создайте и смонтируйте EFI-раздел:

efi раздел
mkfs.fat -F32 /dev/sda1
mkdir -p /mnt/boot
mount --mkdir /dev/sda1 /mnt/boot
6

Установите базовую систему

Установка ядра, базовых утилит и скрипта инициализации. Пакет linux-firmware нужен для драйверов железа.

базовая система
pacstrap /mnt base linux linux-firmware nano
💡 Что за пакеты Пакет — это упакованная программа со всеми файлами и списком того, что ей нужно для работы.
7

Сгенерируйте fstab

Файл /etc/fstab говорит системе, какие разделы монтировать при загрузке.

fstab
genfstab -U /mnt >> /mnt/etc/fstab
8

Зайдите в новую систему

arch-chroot позволяет работать внутри установленной системы из live-окружения.

chroot
arch-chroot /mnt
9

Настройте время, язык, locale

locale
ln -sf /usr/share/zoneinfo/Europe/Moscow /etc/localtime
hwclock --systohc

# Раскомментируйте en_US.UTF-8 и ru_RU.UTF-8 в /etc/locale.gen
nano /etc/locale.gen
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf
10

Задайте пароль root и hostname

root
echo "myarch" > /etc/hostname
passwd
11

Создайте пользователя

Группы wheel дают право на sudo (нужно будет разрешить в sudoers).

пользователь
useradd -m -G wheel -s /bin/bash myuser
passwd myuser
12

Установите загрузчик

Для UEFI — grub:

grub / uefi
pacman -S grub efibootmgr os-prober
mkdir -p /boot/efi
mount --mkdir /dev/sda1 /boot/efi
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg
13

Перезагрузка

готово
exit
umount -R /mnt
reboot

Поздравляем — у вас чистый Arch Linux!

1

Скачайте образ Astra Linux

Astra Linux — российский дистрибутив на базе Debian. Скачайте образ с официального сайта. Special Edition требует регистрацию, Common Edition (Орёл) доступен свободно.

ссылка
https://astra-linux.github.io
2

Создайте загрузочную флешку

Используйте Balena Etcher или Rufus — как для Ubuntu. Образ ISO, флешка от 4 ГБ.

3

Загрузитесь с флешки

Вставьте флешку, войдите в Boot Menu (F12 / F8 / Esc) и выберите «Try or Install Astra Linux».

4

Установите систему

Запустится установщик. Выберите язык, раздел диска, создайте пользователя. При установке Special Edition предложит уровень безопасности (Parsec) — выберите требуемый.

5

Первая команда после установки

После перезагрузки откройте терминал (Ctrl+Alt+T) и обновите систему.

astra linux
sudo apt update && sudo apt full-upgrade -y
1

Скачайте образ RED OS

RED OS — российский дистрибутив на базе RPM (как RHEL/Fedora). Скачайте образ с официального сайта.

ссылка
https://red-soft.ru/download/redos/
2

Создайте загрузочную флешку

Используйте Balena Etcher, Rufus или dd: dd if=redos.iso of=/dev/sdX status=progress.

3

Загрузитесь с флешки

Вставьте флешку, войдите в Boot Menu и выберите «Install RED OS».

4

Установите систему

Запустится графический установщик Anaconda (как в Fedora/RHEL). Выберите язык, раздел диска, создайте пользователя. Укажите тип установки — базовая или рабочая станция.

5

Первая команда после установки

После перезагрузки откройте терминал и обновите систему.

red os
sudo dnf upgrade --refresh -y
[02]

Обновление системы

Регулярно обновляйте систему — это безопасность и стабильность.

1

Обновите списки пакетов

Команда загружает актуальные версии репозиториев, но ещё ничего не ставит.

ubuntu / debian
sudo apt update
2

Обновите все пакеты

ubuntu / debian
sudo apt upgrade
✔ Всё автоматически Флаг -y ответит «да» на все вопросы: sudo apt upgrade -y
3

Полное обновление (опционально)

Обновляет все пакеты, включая те, для которых нужно удалить другие или поставить новые зависимости.

ubuntu / debian
sudo apt full-upgrade
4

Уберите ненужные пакеты

Удаляет зависимости, которые больше не нужны ни одной программе.

ubuntu / debian
sudo apt autoremove
1

Полное обновление системы

В Arch обновление — одна команда. Она обновляет и сами пакеты, и метаданные менеджера пакетов.

arch linux
sudo pacman -Syu
⚠ Важно Не используйте pacman -Sy без u — это приведёт к «partial upgrade» и поломке системы.
2

Обновите AUR-пакеты (если пользуетесь)

AUR — репозиторий пакетов от сообщества. Обычно ставят yay или paru.

aur
yay -Syu
3

Очистите кэш пакетов

Удаляет скачанные архивы установленных программ из кэша.

arch linux
sudo pacman -Sc
1

Обновите списки пакетов

Astra Linux основан на Debian — используется apt.

astra linux
sudo apt update
2

Обновите систему

astra linux
sudo apt full-upgrade -y
💡 Astra vs Ubuntu В Astra рекомендуется full-upgrade вместо upgrade — он надёжнее обрабатывает замену пакетов.
3

Очистите кэш

astra linux
sudo apt clean
1

Полное обновление системы

RED OS использует dnf — менеджер пакетов на базе RPM.

red os
sudo dnf upgrade --refresh -y
⚠ Важно Всегда используйте --refresh или dnf update — это обновит и метаданные, и пакеты одновременно.
2

Очистите кэш

red os
sudo dnf clean all

Удаление программ

1

Удалите программу

Конфигурационные файлы останутся — это безопасно, можно будет вернуть настройки при повторной установке.

ubuntu / debian
sudo apt remove название_пакета
2

Полное удаление с конфигами

ubuntu / debian
sudo apt purge название_пакета
3

Удалите ненужные пакеты

Убирает зависимости, которые были установлены вместе с программой и теперь не нужны.

ubuntu / debian
sudo apt autoremove
✔ Одна команда на всё Удалить программу и почистить ненужные пакеты сразу:
sudo apt purge название_пакета && sudo apt autoremove
4

Удалите Flatpak / Snap

flatpak
flatpak uninstall org.videolan.VLC
flatpak uninstall --unused
snap
sudo snap remove spotify
1

Удалите программу

arch linux
sudo pacman -R название_пакета
2

Удалите программу и ненужные пакеты

Вместе с зависимостями, которые больше не нужны системе.

arch linux
sudo pacman -Rs название_пакета
3

Удалите вместе с конфигами

⚠ Осторожно -Rsc удалит программу, её зависимости и все конфигурационные файлы. Отменить нельзя.
arch linux
sudo pacman -Rsc название_пакета
4

Осиротевшие — это установленные вручную, но больше не нужные. Обычно их удаляют так:

arch linux
sudo pacman -Qdtq
sudo pacman -Rns $(pacman -Qdtq)

Удалите программу

Конфигурационные файлы останутся — это безопасно, можно будет вернуть настройки при повторной установке.

Полное удаление с конфигами

Удалите программу

red os
sudo dnf remove название_пакета

Удалите программу и ненужные зависимости

Флаг autoremove убирает зависимости, которые больше не нужны.

Шпаргалка команд

Основные команды под рукой — по всем четырём дистрибутивам сразу. Нажмите на любую команду, чтобы скопировать её. Установку всегда можно разобрать по шагам, а вот держать команды перед глазами — удобнее.

Ubuntu · apt Arch · pacman Astra Linux · apt RED OS · dnf
Задача Ubuntu Arch Linux Astra Linux RED OS
Обновить списки пакетов sudo apt update не отдельно — см. обновление sudo apt update sudo dnf makecache
Обновить систему sudo apt upgrade sudo pacman -Syu sudo apt full-upgrade sudo dnf upgrade
Установить программу sudo apt install пакет sudo pacman -S пакет sudo apt install пакет sudo dnf install пакет
Удалить программу sudo apt remove пакет sudo pacman -R пакет sudo apt remove пакет sudo dnf remove пакет
Удалить с конфигами и зависимостями sudo apt purge пакет sudo pacman -Rns пакет sudo apt purge пакет sudo dnf remove пакет
Очистить ненужное sudo apt autoremove sudo pacman -Rns $(pacman -Qdtq) sudo apt autoremove sudo dnf autoremove
Найти пакет apt search пакет pacman -Ss пакет apt search пакет dnf search пакет
Информация о пакете apt show пакет pacman -Si пакет apt show пакет dnf info пакет
Список установленных dpkg -l pacman -Q dpkg -l dnf list installed
Установить из файла sudo apt install ./пакет.deb sudo pacman -U пакет.tar.zst sudo apt install ./пакет.deb sudo dnf install ./пакет.rpm
Какие файлы у пакета dpkg -L пакет pacman -Ql пакет dpkg -L пакет dnf repoquery -l пакет

Очистить кэш пакетов sudo apt clean sudo pacman -Sc sudo apt clean sudo dnf clean all
Свежие / уникальные программы flatpak install yay -S пакет flatpak install flatpak install

Словарь терминов

Термины из руководства простыми словами. Наведите на подсвеченное слово в тексте — появится короткое объяснение.

Пакет
Архив с программой: сами файлы, настройки, служебные скрипты и список зависимостей. Система берёт пакет из репозитория и раскладывает его по нужным папкам — так программа устанавливается за секунды. Аналог — установщик .exe в Windows, только централизованно.
Менеджер пакетов
Программа, которая устанавливает, обновляет и удаляет пакеты, сама следит за зависимостями и проверяет подпись разработчика: apt в Ubuntu и Astra Linux, pacman в Arch, dnf в RED OS и Fedora, flatpak и snap — надстройки над ними.
Зависимость
Дополнительный пакет, без которого программа не запустится. Менеджер пакетов подтягивает зависимости автоматически, а после удаления программы они часто остаются «сиротами».
Ненужные пакеты
Остатки удалённых программ: осиротевшие зависимости и старые кэши. Они занимают место на диске. Удаляются командами sudo apt autoremove (Ubuntu, Astra Linux), sudo dnf autoremove (RED OS) и sudo pacman -Rns $(pacman -Qdtq) (Arch).
Репозиторий
Проверенное хранилище пакетов дистрибутива. Команда update лишь обновляет список репозиториев, а upgrade / install уже скачивают из них файлы.
AUR (Arch User Repository)
Репозиторий пакетов от сообщества Arch. Содержит скрипты сборки, а не готовые программы. Ставится через yay или paru.
Терминал
Окно для ввода команд текстом. Быстрее и точнее мышы: одна команда заменяет десяток кликов. Открыть — Ctrl+Alt+T.
sudo
Приставка «выполнить от имени администратора». Нужна для системных действий: установки, удаления, обновления. Без неё система отказывается менять общие файлы.
Дистрибутив
Сборка Linux: ядро + набор программ + менеджер пакетов + оформление. Ubuntu и Astra Linux — на базе Debian (apt, для новичков и госструктур), Arch — «собери сам» (pacman), RED OS — на базе RPM (dnf, российский дистрибутив для бизнеса и госструктур).
Live-флешка
Флешка, с которой Linux запускается без установки — можно всё посмотреть и ничего не испортить на компьютере.
Виртуальная машина
Компьютер внутри компьютера. Linux работает в окне обычной Windows — идеально для тренировки. Программы: VirtualBox, VMware Workstation.
Boot Menu / UEFI
Boot Menu — меню выбора, с чего загружаться (флешка, диск). UEFI — современный аналог BIOS, который управляет загрузкой. Клавиши входа: F12, F8, F10, Esc, Del.
